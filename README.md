# FedRAMP RFI review

Published website: https://pwai.dev/rfi/

Generated static website with 35 submissions organized by eight questions, redacted source answers, AI-assisted summaries and comparisons. Read the [method and limitations](https://pwai.dev/rfi/methodology/).

This repository contains only the generated public website. The original CSV, personal-contact fields, private import tooling and working research files are excluded. No analytics or live AI calls.

GitHub Pages serves the root of the `main` branch; `.nojekyll` preserves Svelte assets.
